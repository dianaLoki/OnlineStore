# Online Store API

REST API для интернет-магазина, разработанное на Django REST Framework. Проект реализует backend для e-commerce с чистой архитектурой и выделением бизнес-логики оформления заказов в изолированный сервисный слой. Выполнено в рамках тестового задания.

## Стек технологий
- Язык: Python 3.11
- Фреймворк: Django 4.2+, Django REST Framework (DRF)
- База данных: PostgreSQL (Django ORM)
- Аутентификация: JWT (djangorestframework-simplejwt)
- Документация API: drf-spectacular (Swagger UI)
- Тестирование: Pytest + pytest-django
- Инфраструктура: Docker, Docker Compose

## Основной функционал

1. Пользователи и Авторизация
- Регистрация и вход по JWT-токену.
- Просмотр профиля пользователя.
- Пополнение виртуального личного баланса для совершения покупок.

2. Каталог товаров
- Просмотр списка товаров и карточки отдельного товара (доступно всем).
- Создание, редактирование и удаление (CRUD) товаров (доступно только администраторам).

3. Корзина покупок
- Добавление товаров в корзину.
- Просмотр текущего состояния корзины.
- Изменение количества товара и удаление позиций.

4. Оформление заказа (Сервисный слой)
- Проверка наличия запрашиваемого количества товара на складе.
- Проверка достаточного количества средств на балансе.
- Транзакционная безопасность: атомарное списание средств и уменьшение остатков.
- Автоматическая очистка корзины после успешного заказа.
- Логирование успешных покупок в консоль.

## Запуск проекта локально

Проект полностью контейнеризирован. Для запуска потребуется только установленный Docker и Docker Compose.

1. Клонируйте репозиторий:

    git clone https://github.com/dianaLoki/OnlineStore.git
    cd OnlineStore

2. Соберите и запустите контейнеры в фоновом режиме:

    docker-compose up --build -d

3. Примените миграции для создания таблиц в БД:

    docker-compose exec web python manage.py migrate

4. Создайте учетную запись администратора (для управления товарами):

    docker-compose exec web python manage.py createsuperuser

## Документация API

После успешного запуска контейнеров интерактивная документация доступна по ссылкам:
- Swagger UI: http://localhost:8000/api/docs/
- OpenAPI Schema: http://localhost:8000/api/schema/

## Тестирование

Проект покрыт unit-тестами с использованием pytest. 
Для запуска тестов выполните команду:

    docker-compose exec web pytest
